# LokAI SDK Demo 使用指南

## 概述

LokAI SDK Demo是一个完整的Android应用示例，展示了如何使用LokAI SDK进行模型管理、推理、对话和性能监控。

## 功能特性

| 功能区 | 说明 |
|--------|------|
| **模型管理** | 加载/卸载GGUF模型文件 |
| **推理功能** | 同步推理和流式推理 |
| **对话功能** | 多轮对话支持 |
| **Tokenizer** | 文本编码/解码测试 |
| **性能监控** | 实时显示推理速度、内存占用等指标 |

## 快速开始

### 1. 准备模型文件

将GGUF格式的模型文件放入设备：

```bash
# 通过ADB推送模型文件
adb push your-model.gguf /sdcard/
```

### 2. 构建运行

```bash
cd lokai/android
./gradlew --no-daemon sample:installDebug
```

### 3. 使用步骤

1. **打开应用**：启动LokAI Demo应用
2. **选择模型**：点击「Browse」按钮选择模型文件
3. **加载模型**：点击「Load Model」按钮
4. **执行推理**：输入提示文本，选择推理模式
5. **查看结果**：在输出区域查看推理结果和性能统计

### 功能区详解

#### 1. 性能监控面板

| 指标 | 说明 | 更新频率 |
|------|------|---------|
| **Status** | 引擎状态（UNINITIALIZED/INITIALIZING/READY/INFERENCING/ERROR） | 实时 |
| **Speed** | 推理速度（tokens/秒） | 推理过程中实时更新 |
| **Memory** | 内存占用 | 推理过程中实时更新 |
| **Tokens** | 已生成token数量 | 推理过程中实时更新 |

#### 2. 模型管理区

| 按钮 | 功能 |
|------|------|
| **Browse** | 打开文件选择器选择模型文件 |
| **Load Model** | 加载选中的模型 |
| **Unload** | 卸载当前加载的模型 |

#### 3. 推理功能区

| 按钮 | 功能 |
|------|------|
| **Complete** | 同步推理（等待完整结果） |
| **Stream Complete** | 流式推理（实时输出token） |

#### 4. 对话功能区

| 按钮 | 功能 |
|------|------|
| **Send** | 发送消息并获取回复 |
| **Clear History** | 清空对话历史 |

#### 5. Tokenizer测试区

| 按钮 | 功能 |
|------|------|
| **Encode** | 将文本编码为token序列 |
| **Decode** | 将token序列解码为文本 |

## 使用示例

### 示例1：基本推理

```
1. 点击 "Browse" 选择模型文件
2. 点击 "Load Model" 加载模型
3. 在推理输入框中输入: "Hello, how are you?"
4. 点击 "Complete" 或 "Stream Complete"
5. 查看输出区域的推理结果
```

### 示例2：多轮对话

```
1. 加载模型
2. 在对话输入框中输入: "Hello"
3. 点击 "Send"
4. 等待AI回复
5. 继续输入: "What's the weather today?"
6. 点击 "Send"
7. 查看对话历史
```

### 示例3：Tokenizer测试

```
1. 加载模型
2. 在Tokenizer输入框中输入: "Hello World"
3. 点击 "Encode" 查看token序列
4. 点击 "Decode" 还原文本
```

## 支持的模型格式

- **GGUF格式**：推荐使用Q4_K_M或Q5_K_M量化版本
- **模型大小**：建议使用7B以下模型以获得较好的性能

## 性能优化建议

1. **选择合适的模型**：较小的模型（如1B-3B参数）推理速度更快
2. **调整线程数**：根据设备CPU核心数调整
3. **使用MMAP**：启用内存映射减少内存占用
4. **限制上下文长度**：根据模型能力设置合理的context window

## 常见问题

### Q: 模型加载失败？

A: 请检查：
- 模型文件路径是否正确
- 模型格式是否为GGUF
- 设备存储空间是否充足

### Q: 推理速度慢？

A: 建议：
- 使用更小的模型
- 降低上下文窗口大小
- 在设置中调整线程数

### Q: 应用崩溃？

A: 请检查：
- 设备是否满足最低要求（Android 7.0+）
- 模型文件是否损坏
- 内存是否充足
