# LokAI SDK

移动端端侧AI推理SDK，基于llama.cpp，支持Android和鸿蒙系统。

---

## 📁 目录结构

```
lokai/
├── doc/                    # SDK项目文档
│   ├── README.md           # 本文档
│   ├── SDK_Development_Guide.md  # SDK开发文档（已存在）
│   ├── api_reference.md    # API参考文档
│   └── CHANGELOG.md        # 更新日志
│
├── android/                # Android平台SDK
│   ├── sdk/                # SDK核心模块
│   └── sample/             # 内置样例
│
├── harmony/                # 鸿蒙平台SDK (v2.0)
│
└── shared/                 # 跨平台共享代码
```
